# 赛后回测与累计样本口径

## 1. 逐场数据键

每场使用 `赛事 + 官方开球时间 + 主队 + 客队` 作为唯一键。重复抓取只更新同一记录，不新增样本。至少保存：

- 正式半场、全场比分及比赛状态。
- 红牌时间、点球、门将伤退和明显争议判罚。
- 赔率公司/追踪源、市场、初盘、严格早于开球的最后赛前盘及其时间戳。
- 1X2去水概率、亚洲盘位与两边价格、大小球、BTTS及波胆簇。

不同公司不得拼成一条变化轨迹。若同源缺少某市场，该市场标记缺失，不使用另一家公司补齐后计入同源命中率。

## 2. 七个独立评价层

1. **基础概率方向**：封盘1X2去水概率最高项是否命中。
2. **显著热度方向**：初盘到封盘去水概率增量最大的结果，且增量通常至少2个百分点。低于显著线记为无明确信号，不进入热度分母。
3. **亚洲盘**：以赛前主盘为准，记录 `W/HW/P/HL/L`。只取得相邻替代盘时单列，不冒充主盘。
4. **大小球**：盘口变档先按最终主线结算；同盘价格变化不足显著线或完全不变时，不计“降赔方向命中”。
5. **BTTS**：只统计同源初盘与封盘均存在且方向有显著变化的比赛。
6. **比分簇**：按主胜零封、主胜双方进球、平局、客胜零封、客胜双方进球评价结构。
7. **精确比分**：强降水单点、相对锁价单点和普通低价单点分开统计。

任何一层命中都不得表述为“整套逻辑命中”。推荐若混合不同玩法，也必须按玩法分别结算。

## 3. 事件修正矩阵

| 事件 | 1X2/亚洲盘 | 大小球/BTTS | 比分簇/精确比分 |
|---|---|---|---|
| 70分钟前红牌且改变局势 | 剔除或重大降权 | 剔除 | 剔除 |
| 结果路径改变的门将伤退 | 受影响方向降权 | 剔除或降权 | 剔除 |
| 争议决定性点球 | 受影响方向降权 | 若跨越盘口线则剔除 | 剔除 |
| 常规点球、无明显争议 | 正常记录 | 标记后正常记录 | 降低单点解释强度 |
| 赛果基本确定后的晚点球 | 通常保留 | 仅跨线市场降权 | 精确比分剔除或降权 |
| 教练红牌、球员人数不变 | 正常记录 | 正常记录 | 正常记录 |

事件修正必须基于事件发生时的比分和比赛状态，不能只看到“有红牌/点球”就整场删除。报告同时展示原始口径与事件修正口径。

## 4. 胜负与净胜球分离

强队欧赔持续强化时，1X2可能是高置信方向，但深盘是否兑现取决于净胜球能力和实际盘口价格。采用以下分层：

| 欧赔 | 深盘两边价格 | 输出 |
|---|---|---|
| 热门显著强化 | 热门低价、受让高价 | 胜负与穿盘可同时升级 |
| 热门显著强化 | 热门高价、受让低价 | 保留热门胜，降低穿盘 |
| 热门稳定 | 深盘频繁跨档 | 只称亚洲盘分歧，不反推1X2 |
| 热门走弱 | 退盘或热门持续升水 | 胜负和穿盘同时降级 |

淘汰赛还需加入首回合比分：领先方的晋级管理首先影响比赛节奏与净胜球诉求。只在欧赔也转弱时，才把“可能保守”升级为胜负风险。

## 5. 波胆簇与单点

- 核心单点：总进球0至4、封盘赔率不高于20，并达到方法文件规定的强降幅线。
- 次核心与尾部只作结构提示，不进入核心精确比分命中率。
- 最终比分赔率很低但没有明显下降，可记“基础低价/相对锁价命中”，不得记为“强降水命中”。
- 晚点球、红牌或门将事件改变最终比分时，精确比分从正常样本中剔除；若事件没有改变所属比分簇，可保留簇方向并注明事件。

## 6. 累计报告

每次报告列出：新增不重复样本、累计样本、各市场原始表现、事件修正后表现、典型误判和规则观察。分母必须显示：

- 缺失市场不进入分母。
- 无显著变化不进入“走势方向”分母。
- 亚洲盘半赢/半输单列，不转成二元命中率。
- 开季前三轮、升班马、五后卫和明显定位球错配标记降信心，但不事后删除。

累计样本较少时不重设数值阈值。新规则至少说明其支持样本、反例和适用范围，并优先增加可证伪的观察字段。

### 两批合并观察（23 场）

- 1X2 主方向 18/23 = 78%；强信号场 100%，弱信号场 0%。
- 大球方向 6 中 1 走，小球方向 3 中 7 错——大球降水信号可信度显著高于小球低水锁价。
- 六条失败模式与修正规则：
  1. 方向升幅 <6% 且亚盘无实质变化 → 定价噪声，不算走弱（支持：奥格斯堡 +5.8% 被 3:0 打破；拉齐奥 44 家升主仍 1:0 小胜）。
  2. 埋伏平需退盘至平手或主水 ≥1.05 且平赔降幅 ≥10%；退盘落点平/半中水 → 判“小胜结构”（支持：拉齐奥 1:0）。
  3. 升盘高水+下盘低水，若欧赔 25+ 家同向压让球方且基本面支持 → 跟欧赔方向，不防下盘（反例：布伦瑞克 3:5、水晶宫 1:4；两场均推下盘失败）。
  4. 热门放松+欧亚分歧时，防范方向升级为并列主方向（支持：里尔巴黎平、波鸿客胜、阿拉维斯主胜，三场反向风险全兑现）。
  5. 低置信度/分歧场默认平局并列主方向（支持：利兹联 1:1；错题 3/3 全在该类）。
  6. 小球需独立证据（降盘+小球 ≤0.85 或进球数据），浅盘小球信号降级（支持：小球 3/10；反例：SB 小球 0.82 锁价的科莫场 3 球、塞尔塔场 2 球）。
- 以上规则写入 SKILL.md 热度判断原则，待下批次验证；样本 23 场，仅作观察项，不重设数值阈值。

- **同批引擎口径**：机械出单 2/3（利兹 ✅、奥萨苏纳 ❌、罗马 ✅）；按 SKILL「压客≥40 且亚盘不配合 → 不出」修正后，实际出单 2/2 + 1 场不出。奥萨苏纳是唯一分歧场。

#### 发现

1. **保护侧是有效变量，固定平赔阈值不是。** 7 场中 6 场命中靠保护侧；唯一错场恰好依赖「平局 4.0+ 不压」。与 SKILL 10-13 批的 1/4 一致，维持不采用。
2. **「有效保护」必须相对化。** 奥萨苏纳客队水位 0.85–0.90，教程读作「没有有效保护」，但按 0.95 绝对值会读成「受保护」——同一数据可得出相反结论。可复现口径：升盘后水位不降 = 假保护；热度侧水位下降且对侧上升 = 真保护。
3. **10-18 的增量价值在奥萨苏纳。** 引擎按压客 48/55=87% 出客队不败，热度法按「客队无有效保护」判主队，实际 2-0；这是热度法能补引擎缺口的一场。罗马场两法同向（主）；利兹场热度法翻客队、引擎留主队不败，平局两边都覆盖。
4. **样本限制**：教程 7 场为选择性发布，不能作为期望命中率；10-18 三场样本过小。建议作为前置观察项，累计 20–30 场前瞻样本后再决定是否升级为出单信号。
5. **奥萨苏纳的引擎缺口仍未修**：`decide()` 只对压客 ≥40 降半档，未实现「亚盘不配合 → 不出」；`test_decide.py` 的「压客 42 → 客队不败」仍是旧口径。本条为观察记录，不改代码。

- 累计样本仍为 271 场（本观察不计数；若未来把 10-18 三场按正式批次记入，271 → 274）。
