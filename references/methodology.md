## 1. 数据完整性

为每个数值记录：公司/来源、市场、盘口或比分、初始赔率、当前赔率、来源更新时间、抓取时间。

按以下可信度排序：

1. 同一公司完整初盘与临盘轨迹。
2. 同一聚合器明确标注的单公司轨迹。
3. 多公司同一时点横向比较。
4. 单一网站当前价格。
5. 搜索摘要或未标注时间的预测文章。

第3至5类不得单独证明“初盘到临盘降水”。不同公司赔付率不同，绝对赔率不可直接拼接。

### 赛前数据硬截点

- 先核对官方计划开球时间与页面时区，再按时间排序赔率记录。
- 优先选取严格早于计划开球时间的最后一条记录作为封盘。恰好落在开球时刻的记录只有在来源明确标记为赛前盘时才能采用。
- 开球后的任何变盘均归入滚球，不得反推为“临盘巨大变化”。若页面不区分赛前与滚球，宁可舍弃边界记录。
- 至少比较初盘、中盘、赛前60分钟和封盘。只有初盘与封盘时，只能描述累计变化，不能判断变化发生在最后一小时。

### 固定公司对照：SBOBET

- 在足彩网公司列表中，SBOBET 以脱敏标签 `ＳＢ/*` 显示。抓取结果中同时保留原始页面标签和标准化公司名 `SBOBET`，便于后续去重。
- 每场优先检查 SBOBET 是否提供欧赔、亚洲盘、大小球及可用的初盘→即时轨迹；公司出现在网站列表中，不代表该场每个市场必然有数据。
- SBOBET 的变化率只能由 SBOBET 自身同一市场、同一盘口口径的初盘与即时价计算。平均盘、澳门盘、Pinnacle 或其他公司的数值只能作为同一时点横向验证。
- SBOBET 与市场平均值方向一致时，提高“多公司共振”置信度；方向相反时标记为单公司分歧，继续检查盘位、返还率和更新时间，不直接判定诱盘或护盘。

## 2. 热度判断顺序

### 先欧后亚

不要用亚盘的深浅或单边水位直接定义市场热度。亚洲盘把结果压缩为上下盘两极，能够通过变盘和水位调整赔付平衡，因此单看亚盘容易把机构的风险管理动作误读为真实热度。

先比较同一公司欧赔胜、平、负三条赔率：

1. 计算三项初赔到临盘的升降幅度。
2. 将赔率转换为隐含概率，并扣除返还率变化的影响。
3. 观察热门项降赔时，平赔和另一侧是否同步抬高。
4. 比较多家公司是否同向，而不是只看单点最低价。

欧赔热度排序完成后，再用亚盘验证：

- 热门方向升盘并降水：顺势强化或保护候选。
- 热门方向降赔但亚盘拒绝升盘：欧强亚浅，防平或诱热候选。
- 热门方向降赔而亚盘退盘：市场分歧，降低置信度。
- 冷门方向欧赔受压，同时亚盘持续降水：冷门保护候选。

最后用大小球、双方进球、波胆和基本面验证比赛剧本。赔率变化只能说明市场价格压力和赔付调整迹象，不能证明具体资金量、散户占比或机构已知赛果。

### 热度法的简化版（外部教程，观察层，10-19 整理）

> **定位**：本节来自用户提供的外部教程，只作**通用层/教学层**，不是独立出单信号。与 SKILL.md 的阈值或优先级冲突时，以 SKILL.md 为准；详细验证见 `backtesting.md` 的「外部热度分析法（简化版）」观察记录。

**四步**

1. **定热度侧**：看欧赔哪一侧在降、亚盘资金往哪边聚。热度侧不等于必然打出方向。
2. **定保护侧**：看哪一边水位被机构按住/压低。**升盘不降水 = 给名气面子，不替你兜底**；保护侧可以与热度侧相反。
3. **定方向**：
   - 热度侧 = 保护侧 → 跟热度（例：主队降赔 + 升盘 + 水位配合）。
   - 热度侧 ≠ 保护侧 → 跟保护侧、反热度（例：客队受热但客队水位没有得到有效保护，主队水位反而被按住）。
   - 盘口越深，退路越少，越需要欧赔和基本面同时佐证；对不上就是诱。
4. **平局赔率**：不得使用「平局 ≥4.0 未压 = 机构防平」的固定阈值（10-13 批 1/4；10-03 压平 42 家仍 1-0；外部教程的罗马-皇马 3-4 亦为反例）。判平仍用 SKILL 的「埋伏平」条件：退盘落平手，或让方水位 ≥1.05，且同公司平赔初→临降幅 ≥10%。

**保护侧的操作化定义**（避免同一水位被读成两种结论）

- **假保护**：盘口升深但让方水位不降或反升；或热度侧水位没有相对下降。
- **真保护**：热度侧水位下降、对侧水位上升；或热度侧水位在盘口维持/升深时持续处于低位。
- 不得只拿水位绝对值判「有效/无效」——同一 0.85–0.90 的受让方水位，在不同盘口和不同初盘下可以读成保护或不保护。必须同时记录初盘→临盘的水位变化和盘口变化。

**边界**

- 主流四家（ＳＢ/*、澳*、易*、36*）的水位方向仍按 10-16 裁定作**基准**（算 dd/wd），不作独立信号源。本节的热度法只作为「热度 + 保护 + 盘口 + 基本面」四条件同时成立的初筛；最终出单仍走 SKILL 现行规则链（规则6、浅盘避雷、压客 ≥40 等）。
- 教程样本是选择性发布，不是随机样本；7 场方向/不败 6/7、亚盘 3W/2P/1L，不能当作期望命中率。后续批次：10-18 3/3 → 10-19 1/4 → 10-20 4/9，累计 8/16 = 50%，维持观察层，不升级为出单信号。
- 身价、状态、交锋只是叙事层，不能替代 SKILL 的硬过滤器（防线/门将 ≥2、德比降档、结构性客场病等）。

## 3. 理论盘位、深浅盘与水位

### 粗略欧亚锚点

以下仅用于常见返还率、平赔与客赔结构没有明显畸形时的快速初筛：

| 主胜欧赔 | 常见亚盘锚点 |
|---|---|
| 1.80左右 | 主让平/半 |
| 1.60至1.70 | 主让半球 |
| 1.45至1.55 | 主让半/一 |
| 1.30至1.40 | 主让一球 |

不得只用主胜单项机械换盘。执行时：

1. 先将胜、平、负三项转换为隐含概率，并消除返还率影响。
2. 检查平赔和客赔形状。同为1.80主胜，低平赔与高平赔对应的理论让步可能不同。
3. 同时记录亚洲盘盘位及两边价格。平/半低水与半球高水可能表达相近的真实定价。
4. 优先比较同一公司欧赔与亚洲盘；不同公司只能用于横向共识。

### 匹配、偏深与偏浅

- **匹配盘**：实际主盘与理论盘接近，先视为中性，再看后续欧亚走势。
- **偏深盘**：实际让步高于理论盘。若热门欧赔同步受压、深盘能够维持且上盘没有持续升水，列为阻买或保护候选；若强开深盘却长期给高水、欧赔不配合，列为诱上或强行造势候选。
- **偏浅盘**：实际让步低于理论盘。若热门欧赔仍持续压低而亚盘拒绝跟进，列为欧强亚浅、诱热或防冷候选；若伤停、轮换或赛程信息能够解释退让，则优先视为基本面重估。

“深盘强队打出”“浅盘必冷”都不是独立规则。至少检查欧赔走势、盘位维持能力、水位路径、多家公司共振和阵容信息。

### 水位解释

使用香港盘水位时，可把0.95以上和0.80以下分别标记为相对高水、相对低水，但必须注明公司、盘口与时间：

> **⚠️ 注记（10-06）：本节 0.95 / 0.80 是「通用相对档」，只用于描述，不是任何规则的触发线。** 立博层另有独立触发线，**两套数不得混用，也不得互相替代**：
> - **≤0.75** = 让方超低水 → **规则6 净胜命题**（立博）
> - **≥1.05** = 深盘高水 → **让球盘不碰**（立博规则 3）
> - **0.08–0.20 的 wd** = 宽平水（立博规则 1，需 dd=0）
>
> 把「0.80 以下低水」当成规则6 触发线是常见误读——**规则6 的门槛是 0.75**。


- 热门高水表示该盘位下回报较高或定价阻力较大，只有欧赔抬升、盘位退让或多家公司同步升水时，才升级为热门风险。
- 热门低水表示该盘位下价格受压，只有欧赔同步压低、盘位稳定或升深时，才升级为保护候选。
- 0.88至0.94一类中水长期僵持只表示水位信息量有限，不能据此排除平局。
- 升盘低水、升盘高水、同盘降水、退盘低水必须分别记录；盘口变半档时，不直接把新旧水位做百分比降幅。

### 名义让球与实际保护

盘口名称只说明结算条件，不说明哪一侧受到价格保护。每次判断必须回答两件事：

1. 欧赔去水概率显示谁是基础热门、平局是否升温。
2. 同一亚洲盘两边价格显示哪一侧赔付被压低，实际盘价与理论应当价偏差多大。

平/半盘的重点复核结构：

- 热门-0.25香港盘水位不低于1.05，受让方+0.25不高于0.82：列为强受让保护候选，而不是热门保护。
- 若同时出现热门欧赔去水概率持平或下降、平局概率上升，归类为“欧主不强、亚护下盘”。1X2层优先考虑热门不胜，再依据客胜和平局的欧赔结构分层，不直接跳到客胜。
- 只有热门欧赔概率同步增强，或亚洲盘有效升至-0.5且热门价格没有重新进入高水，才允许恢复热门胜为主方向。
- 该阈值适用于香港盘格式；其他赔率格式必须先换算，不得直接套用。

### 跨盘水位强制矩阵

盘口从浅档变到深档时，必须同时检查新盘热门水位与下盘水位，不得把“升盘”单独当作保护证据：

| 盘位与水位组合 | 判定 |
|---|---|
| 升盘后热门低水、下盘高水，且欧赔同步强化 | 真正保护或阻买候选 |
| 升盘后热门高水、下盘低水 | 表面升深；优先防下盘，不得称为热门保护 |
| 欧赔强化热门，但亚盘原地不升 | 欧强亚浅；重点防平或热门不穿盘 |
| 欧赔强化热门，亚盘升盘后热门水位快速拉高 | 强化未完成；列为分歧或诱热候选 |
| 退盘后热门低水 | 可能只是等价盘迁移；结合相邻盘后再判断，不自动视为利好 |

执行时记录“旧盘热门水位 → 新盘热门水位”和“新盘两边水位”。若盘口跨档，禁止直接计算单边水位百分比降幅。平/半低水与半球高水、半球低水与半/一高水可能表达相近价格，必须使用相邻盘口或去水后的两边概率校准有效让步。

保护盘至少满足以下两项：热门有效让步增强、热门一侧相对低价、下盘价格没有同步压低、欧赔基础概率稳定或上升。若升盘的同时下盘进入0.85以下低水而热门处于1.00以上高水，默认不是热门保护，除非多家公司与官方阵容提供强确认。

### 临场1至3小时

临场信息价值通常高于早盘，但只有以下链条成立时才升级信号：

1. 同公司欧赔胜平负三项形成清晰配合，而非单项孤立波动。
2. 亚洲盘位或同盘水位同步验证。
3. 至少另一家公司同向。
4. 官方首发、伤停与战术没有明显反证。

临场集体抬升热门欧赔并拉高热门水位，列为热门降温或放弃保护候选；欧亚维稳或同步小幅强化，则保留初始方向。若欧赔稳定、亚盘频繁往返，标记为高分歧赛事，降低结论置信度。

### 最后一小时变化分级

在盘口不变、使用香港盘且来自同一公司的前提下：

- 水位绝对变化小于0.05：通常为维持或噪声，不称“大幅变化”。若低水从早盘持续到封盘，应描述为持续保护。
- 变化0.05至0.08：中等调整，需要欧赔或第二家公司同向确认。
- 变化不小于0.08：大幅异动候选，但仍需排除返还率整体调整和时间越过开球。
- 盘口变化必须按相邻盘等价价格校准。名义升降盘不等于有效让步变化。

因此，复盘失误时先判断信号是“早已存在却被误读”，还是“最后一小时才反转”。不得把持续低水事后解释成突发临盘异动。

## 4. 波胆异常分层

> **⚠️ 覆盖度声明（10-06）：本节是本方法论中唯一「精确但未经验证」的部分。** 截至第 26 批，累计 247 场回测样本**全部集中在 1X2 与亚洲让球盘**，从未检验过波胆市场的任何降幅阈值（`-5% / -8% / -15% / -20%`、`12%`、核心区赔率 `≤20`）。
>
> 这些数字来自早期经验，**不是回测产物**。使用时按「假设」而非「阈值」对待，**不得用它单独出单**。要启用本节，需先跑一批波胆专项回测。

### 赔率区间

- 核心区：总进球0至4，且最新赔率不高于20。
- 次核心区：总进球0至4，但最新赔率20至30。
- 尾部区：最新赔率高于30，或总进球至少5。

区间是筛选工具，不是概率定律。赔率越高，微小绝对调整对应的百分比越夸张，流动性通常也越低。

### 参考降幅

对核心区：

- 0%至-5%：普通波动。
- -5%至-8%：轻度压价。
- -8%至-15%：有意义降水。
- 不高于-15%：强异常候选。

对尾部区：

- 不高于-20%仅称“数字异常”。
- 必须有多家公司同步、对应总进球档下降、主盘方向一致中的至少两项，才能升级为有意义信号。

### 强异常确认

满足以下至少三项，才将某核心比分称为“异常降水”：

1. 同公司初盘到最新下降至少12%，或最后30至60分钟继续明显下降。
2. 最新赔率仍处于核心/次核心区，而非极端高赔。
3. 欧赔或亚盘支持同一胜负方向。
4. 大小球、双方进球或总进球支持该进球结构。
5. 至少另一家公司出现同方向压价。
6. 不是整档高比分赔率被统一压缩。

### 锁价与反向信号

- 某核心比分保持不变，而相邻比分升赔，称“相对锁价”，不是降水。
- 某比分下降，但相应胜负方向和进球结构同时走反，优先标为孤立异常。
- 平局比分1-1、2-2、3-3分别评估；不能因一个平局比分下降就推导所有平局受保护。

## 5. 市场一致性矩阵

| 欧赔 | 亚盘 | 大小/BTTS | 解读 |
|---|---|---|---|
| 某队降 | 向该队升盘或降水 | 同方向比分受压 | 高一致性 |
| 某队降 | 盘位不升 | 中性 | 欧强亚浅，防平/诱热 |
| 某队降 | 该队升水或退盘 | 反向 | 分歧，降低置信度 |
| 客胜降 | 小球与BTTS否降 | 0-1/0-2受压 | 客队零封小胜结构 |
| 主胜降 | 大球与BTTS是降 | 2-1/3-1受压 | 主胜且双方进球结构 |
| 平赔降 | 小球降 | 0-0/1-1受压 | 低比分平局防范 |
| 热门欧赔不强或走弱 | 热门-0.25高水、受让+0.25超低水 | 中性 | 强受让保护，优先热门不胜 |

同时检查欧赔返还率变化。某一项下降可能只是整体调低利润率，而不是单独方向强化。

### 三类实战结构

- **正路候选**：欧赔与理论亚盘匹配，热门项持续受压，亚盘维持或升盘降水，基本面没有反证。
- **诱上候选**：热门优势一般但盘位表面强势，或实际盘偏浅却提供便宜热门价格；同时存在欧赔、盘位维持能力或阵容反证。
- **埋伏平候选**：平赔同公司持续下降，胜负两端配合抬高，亚洲盘不动或横摆，并由小球、BTTS否、0-0或1-1至少一项验证。

口诀可以概括为“欧赔定基调，亚盘看保护；同步增强正路，背离提高防冷；临场看共振”，但不得用口诀替代数据表和验证链。

### 胜负强度与净胜球强度

1X2回答谁更可能获胜，亚洲深盘回答需要赢几球；两者不能用同一命中结论替代。欧赔热门显著强化，但深盘热门高水、受让方低水时，先保留热门胜方向，同时降低穿盘与大胜置信度。淘汰赛首回合领先只自动降低净胜球和进球节奏预期，不自动推翻热门胜。

## 6. 诱盘与护盘

### 护盘候选

- 核心比分低价并持续锁价。
- 最后阶段二次降水。
- 该比分下降，而相邻结果升赔。
- 欧亚、大小球或BTTS至少一项同步。

### 诱盘候选

- 热门方向赔率看似便宜，但让球盘拒绝升盘。
- 降水同时伴随可承受的高水和更深盘缺失。
- 市场叙事极热，但关键阵容或赛程不支持。
- 波胆只在单一公司下降，其他公司保持高价。

使用“候选、倾向、迹象”等措辞，不断言庄家真实意图。

## 7. 基本面验证

将基本面映射到具体盘口：

- 中锋或主要创造者缺阵：降低球队进球上限，检查大小球和零封比分。
- 中卫/门将缺阵：提高对手进球与BTTS概率。
- 双方同阵型不代表节奏相同；重点看压迫高度、边翼卫站位和转换方式。
- 杯赛轮换、三天一赛、长途旅行和极端天气可以解释临盘退盘，但需要可靠来源。
- 强受让保护与小球低水并存时，额外检查受让方反击速度、热门落后后的追分倾向和BTTS市场。受让方具备先进球能力时，小球与下盘不是天然同向，必须拆开判断。

## 8. 复盘诊断清单

每场判断错误后依次回答。**顺序不可颠倒：先查 A 立博层。** 247 场样本（截至第 26 批）里决定胜负的主要是这一层；先查通用层会漏掉关键项——典型如第 26 批冰岛-保加利亚，通用层看不出任何问题，错在「深盘高水 vs 受让方超低水」的冲突没被识别。

### A. 立博层（必查，先做）

1. **dd = 多少**（`|立博盘口| − |主流盘口中位数|`）？落在哪档：**≤−0.25** 浅盘 / **0** 同盘 / **≥0.5** 深盘？
2. **wd = 多少**（`|立博让方水位 − 主流让方水位中位数|`）？是否触及 **0.205** 线？（注意：这条阈值卡在千分位，wd 恰为 0.20 与 0.205 在报价上没有区别——**遇到 0.20 应按触发处理并标注**。）
3. **立博让方水位**落在哪档：**≤0.75** 超低 / 0.75–0.95 / 0.95–1.05 / **≥1.05** 深盘高水？
4. **触发了哪条规则**：规则1 宽平水 / 规则2 浅盘警示 / 规则3 深盘高水 / 规则6 让方超低水锁价 / 浅盘避雷（dd ≤−0.25 且让方水 >0.75）？
5. **规则6 与压价共识方向是否一致**？**冲突时以规则6 为准**，不得套用「不输出强单边」——第 25 批波兰-罗马尼亚 6:0 是铁证：规则6 全条件成立、压客 30 家反向，我按冲突条款不出单，结果规则6 以最大分差命中。
6. **深盘高水与受让方超低水是否同时出现**？是则**该场让球盘一律不碰，不得选边**——第 26 批冰岛-保加利亚：让方 1.20（深盘高水）+ 受让方 0.60（超低），我按后者选了受让方 +1.5，赛果 3:0 完败。
7. **主方向是否来自「受让方超低水」路径**？是则输出**必须是「不败」而非「胜」**；且**只有平手/半球盘口下，「让球盘不败」才等价于「1X2 不败」**，球半及以上只保护让球盘。第 24 批希腊（2:2）、第 25 批波黑（1:1）两次都是方向判对、命题写错。
8. **立博让方水位轨迹**：单调降水 / 升水 / 横盘？最新一条时间戳距开球多久？**锁价越晚越值钱**。
9. **数据质量硬过滤（10-22 新增）**：立博盘口是否缺失？立博轨迹最新时间距开球是否 **>72 小时**（补赛/盘口未重开）？是则**不出正式单，最多观察**，不得用基础概率/压价共识替代立博结构。

### B. 共识与热度层

9. **压价家数**（主/平/客各多少）？对照全域家数（通常 40–43）**看占比，不看绝对数**。
10. **压客 ≥40 时，立博让方是否同向持续降水**？是则正常出单；否则不出。第 26 批压客 43（→7:0）与 41（→2:0）双中，共同点正是让方水位四条单调降水；历史打反场（诺维奇、蔚山、莱比锡、巴黎）则都是「欧强亚浅」。
11. **热度 Δpp**：威\*/立\*/韦\* 三家统一返还率归一后，是否有单项越过 **±5pp**？热度方向在亚盘是否获得保护（让方水位 **≤0.95**）？
12. **压平家数只作环境描述，不得作为出单依据**（第 26 批裁定：≥30 家累计 6/8，且史上最高读数 42 家仍打出 1:0）。

### C. 通用欧亚层

13. 欧赔基础热门是谁，三项去水概率分别如何变化？
14. 亚洲盘名义让球方是谁，实际低价保护方又是谁？
15. 实际价格相对理论应当价格偏差是否至少 0.05？
16. 保护从早盘持续存在，还是最后 60 分钟才出现？
17. 最后 60 分钟是否达到同盘 0.08 或有效变盘的大幅异动线？**同源是否真的刷新了**——页面哈希变了但赔率数值一字未动，等于「未刷新」，不得包装成变化（第 26 批评测实践：23:47 复检五项指标全同，据此维持原判、未改单，五单全中）。
18. 大小球、BTTS 与球队进球数是否真正形成确认链？

### D. 事件层

19. 是否混入开球后滚球数据？（硬截点 = 官方计划开球时间，严格取早于开球的最后一条）
20. 红牌、点球、门将伤退等重大事件是否改变正常路径？需按市场分别剔除，不整场作废。
21. **本批赛事基准率是多少**（主胜/客胜/平局各占比）？**命中率必须与基准率一起读**——单批战绩离开基准率就没有意义。第 24 批平局基准 62.5%（我唯一命中单几乎零信息量）、第 26 批平局基准 0%（压平信号无从兑现），是两个相反的典型。

## 9. 推荐措辞

输出概率层级，而不是保证：

- 主方向：欧亚和基本面同时支持。
- 次方向：盘口支持但存在一项冲突。
- 防范方向：赔率有保护迹象但概率较低。
- 反向风险：欧亚冲突、阵容突变或数据源不完整。

明确提醒赔率只表达市场价格，不保证赛果；用户据此投注时应自行控制风险。

赛后累计统计与事件修正的完整执行口径见 [backtesting.md](backtesting.md)。
